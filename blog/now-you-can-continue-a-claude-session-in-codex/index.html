Now you can continue a Claude session in Codex, and vice versa

Convert Claude sessions to Codex and back with open-source agent-convert.

By Harsh Gupta · July 8, 2026

Both Claude and Codex are great harnesses, and I find myself switching between them quite a lot. Sometimes I want to continue a Claude session in Codex, or a Codex session in Claude. Often this happened because of running out of session limits, so I got agents to write a tool for me to convert between various harnesses. Today, I'm using open-source agent-convert, enjoy!

GitHub: https://github.com/theoriclabs/agent-convert
